# Jamilah Maysa / Jamilah's Jam

Static, GitHub + Vercel ready website.

## Deploy
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Vercel, choose **Add New Project** and import the repository.
4. Framework preset: **Other**. No build command is required.
5. Output directory: leave blank / repository root.
6. Add `jamilahmaysa.com` in Vercel Domains and point DNS as Vercel instructs.

## Current content rules
- Live class times are intentionally not hard-coded because the timetable changes.
- Booking CTAs currently route to @jamilahs_jam on Instagram until a booking/payment link is supplied.
- No invented testimonials, qualifications or pricing have been added.

## Main files
- `index.html` — homepage
- `styles.css` — full responsive visual system
- `script.js` — video viewport handling + footer year
- `locations/*/index.html` — first 10 local SEO pages
- `assets/` — supplied Jamilah media
- `sitemap.xml`, `robots.txt`, `vercel.json` — deployment/SEO support
