# Jamilah's Jam website

Production-ready static site for **https://www.jamilahsjam.com**.

## Deploy to GitHub + Vercel
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In Vercel, choose **Add New Project** and import the repository.
4. Framework preset: **Other**. No build command is required.
5. Deploy.
6. Add `jamilahsjam.com` and `www.jamilahsjam.com` in Vercel Domains, then follow Vercel's DNS instructions.

## Before the final public launch
- Connect the gig form to a real CRM/webhook if desired. The current form works without a backend by copying the enquiry and opening Instagram DM.
- Add Jamilah's preferred business email and phone/WhatsApp only when confirmed.
- Add current class times to `/timetable/` if Jamilah wants them hard-coded.
- Add verified reviews to `/community/` once permission is available.
- Replace or compress video files further if you want even faster mobile performance.
- Update any event pages with actual dates using Event schema only after events are confirmed.

## Commercial architecture
The site is designed around multiple revenue routes, not classes alone: weekly classes, private dance sessions, private parties, corporate wellbeing/team building, community/council events, workshops/pop-ups, performance/choreography, and later digital products or membership.
